📚 Library Management System

A console-based Library Management System developed in C++ using Object-Oriented Programming (OOP) concepts.

🚀 Features

- Add books to the library
- Add customers
- Register permanent and regular members
- Display all books
- Display registered customers
- Borrow books
- Return books
- Calculate late-return fines
- Permanent members are exempt from late fines
- Search books by title or author
- View books borrowed by a specific customer
- Track total fines for customers

🛠️ Technologies Used

- C++
- Object-Oriented Programming (OOP)
- C++ Standard Library
- "iostream"
- "vector"
- "string"

▶️ How to Run

Using Dev-C++

1. Open Dev-C++.
2. Open "main.cpp".
3. Compile the program.
4. Run the program.
5. Follow the options displayed in the console.

Using a C++ Compiler

Compile the program with:

g++ main.cpp -o library

Then run:

./library

💰 Fine System

Regular members receive a fine of $5 per extra day after the initial 7-day borrowing period.

Permanent members are exempt from late-return fines.
